# Moramba Singh — Personal Portfolio

Files:
- index.html — complete responsive portfolio
- profile.jpg — provided profile photo

Run locally:
1. Keep index.html and profile.jpg in the same folder.
2. Double-click index.html, or use VS Code Live Server.

Deploy:
- GitHub Pages: upload both files to a repository and enable Pages.
- Netlify/Vercel: drag the folder into the deployment interface or connect the repository.
